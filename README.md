Project Overview:
OUT OF FRAME is a proposed system for planning, organizing, tracking, reviewing, and documenting AI-assisted film production. Its first case study is the seven-minute human drama برّه الصورة (Out of Frame), which uses minimal dialogue and visual storytelling.
